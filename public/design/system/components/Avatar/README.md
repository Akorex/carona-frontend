Avatar shows a person's initials in a disc; the app has no profile photos yet.

**Props the consumer provides:** `name` (first and last name from the API) and optional `size` (`sm` 32px, `md` 40px, `lg` 64px).

**Do**
- Use `sm` inside ride cards, `md` in lists of passengers, `lg` at the top of Profile.

**Don't**
- Don't use it as the only way to tell people apart. Always show the name next to it.
